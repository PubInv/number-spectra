Start with three simple steps.

No coding needed to explore OEIS sequences.

01

Load a few sequences

In the app's Sequence loader, enter OEIS IDs separated by commas, spaces, or newlines. Try primes and Fibonacci numbers:

40, 45

Select Load, or press Ctrl / ⌘ + Enter inside the OEIS field.

02

Choose your perspective

Begin with Overlaps to find shared values. Switch to Lanes to separate sequences, or Density to compare where terms are concentrated.

03

Follow a number

Drag to pan and use the mouse wheel to zoom. Click a value to inspect it in Details. Try searching for 13 with Jump to find it in both example sequences.

One number line. Three ways to look.

Change views with the buttons in the app's top bar.

Overlaps

What do they share?

Explore exact values on a shared axis. Labels identify values found in multiple enabled sequences. Click a nearby-values label to list its contents; double-click it to zoom in.

Lanes

How do they compare?

Give each sequence its own row. Hover over a term to connect matching lanes, then click to select it. Dense ranges appear as compact strips until you zoom in.

Density

Where do terms gather?

Use Total for combined counts, Compare for stacked sequence counts, or Normalized to scale each sequence to its own peak in the current view. Hover for counts; click a range to zoom.

Good to know

Keep these in mind as you explore.

  • Start small. Two or three sequences are easier to compare. Use the checkboxes under Sequences to hide or show them on the main plot.
  • Try Log X for wide ranges. It uses a signed logarithmic scale, so zero and negative values still work.
  • Make room for the graph. The small arrow buttons collapse the Sequence loader and Details panels.
  • Loaded terms are a sample. The app uses the terms returned by OEIS, not every term in an infinite sequence. A missing result doesn't prove a number isn't in the sequence.
  • Use a desktop for the full workspace. The current app is built around a mouse and keyboard.

Before you launch

What is OEIS, and which IDs can I enter?

The On-Line Encyclopedia of Integer Sequences catalogs integer sequences. This app accepts forms such as 40, 000040, or A000040. Use 40, 45 to compare primes with Fibonacci numbers.

Can I create my own sequence?

Yes. In Custom sequence, set the term count and write JavaScript that adds numbers to the array a. The variable n is your requested count. For example, generate squares:

for (let i = 0; i < n; i++) {
  a.push(i * i);
}

Select Compute to run it in a browser worker with a short timeout. Use code you understand and trust. Only one custom sequence is kept at a time; computing another replaces it.

Why isn't a sequence loading?

Check the ID and your connection. Loading OEIS data requires the Node server and access to OEIS. If several IDs fail, try one at a time and check the browser console or server output for details. The welcome page itself doesn't contact OEIS.

Will my sequences be saved?

The current app keeps its workspace in this tab's memory. Refreshing or leaving it clears the workspace. Loading OEIS IDs also replaces the current set, including a custom sequence. Keep a copy of IDs or custom code you want to use again.

Why do I see grouped values or large-number formatting?

Nearby values are grouped when labels won't fit; zoom in or select the group to inspect them. Axis labels may be rounded for readability. The app also uses JavaScript numbers, so integers beyond 9,007,199,254,740,991 may lose precision; avoid relying on exact overlap results for those values.
